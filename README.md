# fionngavin.dev

Personal site of [Fionn Gavin](https://fionngavin.dev) — computer science student at Trinity College Dublin, working on security and systems.

Built with [Astro](https://astro.build). Live at [fionngavin.dev](https://fionngavin.dev).

## Stack

- Astro 5
- MDX for writing
- Content collections for projects and posts
- Geist (variable) for type
- Deployed to GitHub Pages

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build    # output to dist/
npm run preview  # preview production build
```

## Structure

```
src/
  pages/          # routes (home, about, contact, projects, writing)
  content/        # projects and blog collections
  components/     # nav, footer
  layouts/        # base document
  styles/         # global design tokens and styles
public/           # static assets, CNAME
```
